# 🎟️ Support Ticket Classification & Prioritization

## 📌 Project Overview
This project uses Machine Learning to automatically classify support tickets and assign priority levels.

## 🚀 Features
- Ticket classification using NLP
- Priority prediction (High / Medium / Low)
- Data visualization (graphs & charts)
- WordCloud analysis
- Confidence score analysis
- Ticket summary generation

## 🛠️ Technologies Used
- Python
- Scikit-learn
- NLTK
- Pandas
- Matplotlib & Seaborn

## 📊 Model Used
- Logistic Regression
- TF-IDF Vectorization

## 🎯 Results
- Achieved ~85% accuracy
- Successfully categorized tickets into multiple classes

## 💡 Business Use
- Helps support teams respond faster
- Reduces manual work
- Improves efficiency

- Jupyter Notebook (.ipynb)
- Dataset used
